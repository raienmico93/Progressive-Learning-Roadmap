# Classic Backtracking Problems: Comprehensive Programming Cheat Sheet

## Topic Overview

### Definitions

**Core Definition**
Classic backtracking problems are well-known algorithmic puzzles that exemplify the systematic search of a solution space by building candidates incrementally and abandoning partial solutions that cannot lead to valid answers.

**Technical Definition**
These problems share a common structural pattern: a state-space tree where each level represents a decision, and pruning criteria eliminate branches that violate constraints or cannot improve upon known bounds. Solutions are generated by depth-first traversal with state restoration (choose-explore-unchoose).

**Beginner-Friendly Explanation**
These are the "greatest hits" of backtracking—problems that appear repeatedly in interviews, textbooks, and competitions because they beautifully illustrate how to systematically explore all possibilities while avoiding dead ends.

### Key Characteristics

- **Exponential Search Spaces**: Most have O(2^n) or O(n!) potential solutions, necessitating pruning.
- **Constraint-Based Pruning**: Invalid partial solutions are detected and abandoned early.
- **State Restoration**: The choose-explore-unchoose pattern is universal across all problems.
- **Canonical Patterns**: Each problem teaches a reusable technique applicable to broader classes.

### Prerequisites

- Recursion and call stack fundamentals
- Backtracking template (choose, explore, unchoose)
- Basic data structures (arrays, sets, graphs)
- Bit manipulation (for optimized state tracking)

### Related Programming Areas

- **Constraint Satisfaction**: Scheduling, planning, puzzle solving
- **Combinatorial Optimization**: Knapsack, TSP, graph coloring
- **Game AI**: Decision trees, minimax with pruning
- **Compiler Design**: Pattern matching, parsing

### Core Concepts

| Problem | Search Space | Key Pruning |
|---------|-------------|-------------|
| N-Queens | n^n | Column/diagonal attack detection |
| Subsets | 2^n | None (exhaustive) |
| Permutations | n! | Used-element tracking |
| Combinations | C(n,k) | Remaining-elements bound |
| Maze Solving | Exponential | Visited marking, wall detection |
| Sudoku | 9^m | Row/col/box constraint sets |
| Word Search | 4^L | Grid bounds, character match |
| Graph Coloring | k^n | Adjacent vertex conflict |
| 0/1 Knapsack | 2^n | LP relaxation upper bound |
| Hamiltonian/TSP | (n-1)! | Reachability, degree constraints |


## 1. N-Queens

### Definitions

**Core Definition**
The N-Queens problem asks for all ways to place N queens on an N×N chessboard such that no two queens attack each other (no shared row, column, or diagonal).

**Technical Definition**
Given an N×N board, find all permutations of column positions (one queen per row) such that no two queens share a column (`col` distinct), main diagonal (`row - col` distinct), or anti-diagonal (`row + col` distinct) .

**Beginner-Friendly Explanation**
You have N queens and an N×N board. You must place them so none can capture another. Since queens attack horizontally, vertically, and diagonally, each row, column, and diagonal can have at most one queen.

### Purposes (All begin with "To")

- **To** demonstrate constraint satisfaction with multiple interacting constraints
- **To** teach O(1) conflict detection using sets or boolean arrays
- **To** illustrate pruning: invalid placements are detected immediately 
- **To** serve as a benchmark for backtracking efficiency

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def solve_n_queens(n):
    results = []
    cols, diag1, diag2 = set(), set(), set()
    
    def backtrack(row, board):
        if row == n:
            results.append(board[:])
            return
        for col in range(n):
            if col in cols or (row-col) in diag1 or (row+col) in diag2:
                continue  # PRUNE
            cols.add(col); diag1.add(row-col); diag2.add(row+col)
            board.append(col)
            backtrack(row + 1, board)
            board.pop()  # UNCHOOSE
            cols.remove(col); diag1.remove(row-col); diag2.remove(row+col)
    
    backtrack(0, [])
    return results
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `cols` | Set of occupied columns |
| `diag1` | Set of occupied main diagonals (`row - col`) |
| `diag2` | Set of occupied anti-diagonals (`row + col`) |
| `board` | Column positions for each row |

**Syntax Rules**

- Place exactly one queen per row (eliminates row attacks automatically)
- Check column, main diagonal, and anti-diagonal before placing 
- Use sets or boolean arrays for O(1) conflict detection 

### Annotated Code Examples

**Example 1: N-Queens with Attack Sets (Python)**

```python
    diag1   = set()  # row - col
    diag2   = set()  # row + col

            results.append(board[:])

            board.pop()
            cols.remove(col)
            diag1.remove(row - col)
            diag2.remove(row + col)

    return results
```

## 2. Subsets (Power Set)

### Definitions

**Core Definition**
The subsets problem asks for all possible subsets (the power set) of a given set of distinct elements .

**Technical Definition**
For an array `nums` of n distinct elements, generate all 2^n subsets, where each element is either included or excluded from each subset. The solution set contains no duplicate subsets .

**Beginner-Friendly Explanation**
Given a set of items, list every possible combination—from the empty set to the full set. For [1,2,3], you'd list: {}, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}.

### Purposes (All begin with "To")

- **To** demonstrate binary decision trees (include/exclude)
- **To** teach exhaustive enumeration without pruning
- **To** provide foundation for combination and permutation problems 
- **To** illustrate the 2^n search space

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def subsets(nums):
    result = []
    path = []
    
    def backtrack(index):
        if index == len(nums):
            result.append(path[:])
            return
        # Exclude nums[index]
        backtrack(index + 1)
        # Include nums[index]
        path.append(nums[index])
        backtrack(index + 1)
        path.pop()  # UNCHOOSE
    
    backtrack(0)
    return result
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `index` | Current element to decide on |
| `path` | Current subset being built |
| `include/exclude` | Two recursive branches |

**Syntax Rules**

- At each index, make two recursive calls: one without the element, one with it 
- Record the subset when `index == len(nums)` (end of decision tree) 
- Copy `path` before appending to results (avoid reference aliasing)

### Annotated Code Examples

## 3. Permutations

### Definitions

**Core Definition**
The permutations problem asks for all possible orderings of a set of distinct elements .

**Technical Definition**
For n distinct elements, generate all n! permutations. At each step, choose an unused element, place it in the next position, and recurse until all positions are filled .

**Beginner-Friendly Explanation**
Given a set of items, list every possible way to arrange them in order. For [1,2,3]: 123, 132, 213, 231, 312, 321.

### Purposes (All begin with "To")

- **To** demonstrate state tracking with used-element markers
- **To** teach the n! search space and its generation
- **To** provide foundation for scheduling and ordering problems 
- **To** illustrate swap-based backtracking 

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def permute(nums):
    result = []
    used = [False] * len(nums)
    path = []
    
    def backtrack():
        if len(path) == len(nums):
            result.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack()
            path.pop()
            used[i] = False
    
    backtrack()
    return result
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `used` | Boolean array tracking picked elements |
| `path` | Current permutation being built |
| `len(path) == n` | Base case: complete permutation |

**Syntax Rules**

- Track used elements to avoid repetition 
- Base case: when path length equals input length 
- Alternative: swap elements in-place and recurse 

### Annotated Code Examples

**Example 1: Permutations with Used Array (Python)**


## 4. Combinations

### Definitions

**Core Definition**
The combinations problem asks for all ways to choose k elements from a set of n elements, where order does not matter .

**Technical Definition**
Generate all k-sized subsets of {1, 2, ..., n}. To avoid duplicates, elements are chosen in increasing order, and the recursion tracks a `start` index .

**Beginner-Friendly Explanation**
Given numbers 1 through n, choose k of them. The order doesn't matter—{1,2} is the same as {2,1}. For n=4, k=2: {1,2}, {1,3}, {1,4}, {2,3}, {2,4}, {3,4}.

### Purposes (All begin with "To")

- **To** demonstrate combination generation with duplicate avoidance
- **To** teach the `start` index pattern for ordered selection 
- **To** provide foundation for subset-sum and knapsack problems
- **To** illustrate pruning with remaining-element bounds 

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def combine(n, k):
    result = []
    path = []
    
    def backtrack(start):
        if len(path) == k:
            result.append(path[:])
            return
        # Prune: need k - len(path) more; stop if not enough remain
        remaining = k - len(path)
        for i in range(start, n - remaining + 2):
            path.append(i)
            backtrack(i + 1)  # i+1 ensures increasing order
            path.pop()
    
    backtrack(1)
    return result
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `start` | First index available for selection |
| `path` | Current combination |
| Pruning bound | `n - remaining + 2` stops when not enough elements remain  |

**Syntax Rules**

- Use `start` index to avoid permutations of the same combination 
- Prune when remaining elements are insufficient 
- Pass `path` by reference and pop after recursion 

### Annotated Code Examples

**Example 1: Combinations with Pruning (Python)**

```python
def combine(n, k):
    """Return all k-combinations of 1..n."""
    result = []
    path = []
    
    def backtrack(start):
        # Base case: k elements chosen
        if len(path) == k:
            result.append(path[:])
            return
        
        # PRUNE: need (k - len(path)) more elements
        # Largest start that still allows enough: n - remaining + 1
        remaining = k - len(path)
        for i in range(start, n - remaining + 2):
            path.append(i)          # CHOOSE
            backtrack(i + 1)        # EXPLORE (i+1 for increasing)
            path.pop()              # UNCHOOSE
    
    backtrack(1)
    return result


# Demonstration

combos = combine(n, k)
print(f"All {k}-combinations of 1..{n}:")
for c in combos:
    print(f"  {c}")
print(f"\nTotal: {len(combos)} = C({n},{k})")
```

**Expected Output:**
```
All 2-combinations of 1..4:
  [1, 2]
  [1, 3]
  [1, 4]
  [2, 3]
  [2, 4]
  [3, 4]

Total: 6 = C(4,2)
```

**Why This Output Occurs**: The `start` index ensures increasing order (1 then 2, but not 2 then 1). The pruning condition `n - remaining + 2` stops the loop early when insufficient elements remain to complete the combination .

## 5. Maze Solving (Grid Traversal)

### Definitions

**Core Definition**
Maze solving is the problem of finding a path from a start position to an end position in a grid containing obstacles .

**Technical Definition**
Given an N×N grid where 1 represents walls and 0 represents open cells, find a path from start to end moving in four directions (up, down, left, right), never revisiting a cell .

**Beginner-Friendly Explanation**
You're in a maze with walls. You try moving in each direction until you find the exit. If you hit a wall or a dead end, you go back and try a different direction.

### Purposes (All begin with "To")

- **To** demonstrate grid traversal with backtracking
- **To** teach visited marking and state restoration 
- **To** provide foundation for pathfinding algorithms
- **To** illustrate backtracking vs. DFS differences 

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def solve_maze(maze, start, end):
    rows, cols = len(maze), len(maze[0])
    visited = [[False] * cols for _ in range(rows)]
    path = []
    
    def backtrack(r, c):
        if (r, c) == end:
            path.append((r, c))
            return True
        if not (0 <= r < rows and 0 <= c < cols) or maze[r][c] == 1 or visited[r][c]:
            return False
        
        visited[r][c] = True
        path.append((r, c))
        
        for dr, dc in [(0,1), (0,-1), (1,0), (-1,0)]:
            if backtrack(r + dr, c + dc):
                return True
        
        path.pop()  # UNCHOOSE
        visited[r][c] = False
        return False
    
    return backtrack(*start)
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `visited` | Tracks cells in current path |
| `path` | Records the solution route |
| Directions | Four movement options |

### Annotated Code Examples

**Example 1: Maze Solver with Path Tracking (Python)**

```python
def solve_maze(maze, start, end):
    """Find a path from start to end in maze. 1=wall, 0=open."""
    rows, cols = len(maze), len(maze[0])
    visited = [[False] * cols for _ in range(rows)]
    path = []
    
    def backtrack(r, c):
        # Base case: reached end
        if (r, c) == end:
            path.append((r, c))
            return True
        
        # Invalid: out of bounds, wall, or visited
        if not (0 <= r < rows and 0 <= c < cols):
            return False
        if maze[r][c] == 1 or visited[r][c]:
            return False
        
        # CHOOSE: mark visited, add to path
        visited[r][c] = True
        path.append((r, c))
        
        # EXPLORE: try all four directions
        for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
            if backtrack(r + dr, c + dc):
                return True
        
        # UNCHOOSE: backtrack
        path.pop()
        visited[r][c] = False
        return False
    
    if backtrack(start[0], start[1]):
        return path
    return None


# Demonstration
maze = [
    [0, 0, 0, 0],
    [1, 1, 0, 1],
    [0, 0, 0, 0],
    [0, 1, 1, 0]
]
start = (0, 0)
end = (3, 3)

path = solve_maze(maze, start, end)
if path:
    print(f"Path found ({len(path)} steps):")
    print(f"  {path}")
else:
    print("No path exists")
```

**Expected Output:**
```
Path found (7 steps):
  [(0, 0), (0, 1), (0, 2), (0, 3), (1, 3), (2, 3), (3, 3)]
```

**Why This Output Occurs**: The algorithm tries directions in order (right, left, down, up). It finds a path along the top row, down the right side, to the end. Backtracking restores state when paths fail .

## 6. Sudoku Solver

### Definitions

**Core Definition**
Sudoku is a 9×9 grid puzzle where each row, column, and 3×3 box must contain digits 1-9 exactly once .

**Technical Definition**
Given a partially filled 9×9 board with empty cells (`.`), fill all cells satisfying row, column, and box constraints. Use backtracking with O(1) constraint checking via sets .

**Beginner-Friendly Explanation**
Sudoku is a logic puzzle where you fill in missing numbers. Each number 1-9 appears exactly once in every row, column, and 3×3 square. Backtracking tries digits and undoes them when they lead to contradictions.

### Purposes (All begin with "To")

- **To** demonstrate backtracking with multiple constraint types
- **To** teach efficient constraint tracking with sets/bitmasks 
- **To** illustrate propagation of constraints
- **To** provide a challenging, practical backtracking problem

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def solve_sudoku(board):
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]
    
    # Initialize constraints
    for r in range(9):
        for c in range(9):
            if board[r][c] != '.':
                val = board[r][c]
                rows[r].add(val); cols[c].add(val)
                boxes[(r//3)*3 + c//3].add(val)
    
    def backtrack(r, c):
        if r == 9: return True
        if c == 9: return backtrack(r+1, 0)
        if board[r][c] != '.': return backtrack(r, c+1)
        
        box_idx = (r//3)*3 + c//3
        for d in map(str, range(1, 10)):
            if d not in rows[r] and d not in cols[c] and d not in boxes[box_idx]:
                board[r][c] = d
                rows[r].add(d); cols[c].add(d); boxes[box_idx].add(d)
                if backtrack(r, c+1): return True
                board[r][c] = '.'
                rows[r].remove(d); cols[c].remove(d); boxes[box_idx].remove(d)
        return False
    
    backtrack(0, 0)
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `rows[i]` | Set of digits in row i |
| `cols[j]` | Set of digits in column j |
| `boxes[k]` | Set of digits in 3×3 box k |
| Box index | `(r//3)*3 + c//3`  |

### Annotated Code Examples

**Example 1: Sudoku Solver with Constraint Sets (Python)**

```python
def solve_sudoku(board):
    """Solve Sudoku in-place."""
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]
    
    # Initialize constraint sets from given digits
    for r in range(9):
        for c in range(9):
            if board[r][c] != '.':
                val = board[r][c]
                rows[r].add(val)
                cols[c].add(val)
                boxes[(r // 3) * 3 + c // 3].add(val)
    
    def backtrack(r, c):
        # Base case: all rows processed
        if r == 9:
            return True
        # Move to next row
        if c == 9:
            return backtrack(r + 1, 0)
        # Skip filled cells
        if board[r][c] != '.':
            return backtrack(r, c + 1)
        
        box_idx = (r // 3) * 3 + c // 3
        
        # Try digits 1-9
        for d in map(str, range(1, 10)):
            if d not in rows[r] and d not in cols[c] and d not in boxes[box_idx]:
                # CHOOSE
                board[r][c] = d
                rows[r].add(d)
                cols[c].add(d)
                boxes[box_idx].add(d)
                
                # EXPLORE
                if backtrack(r, c + 1):
                    return True
                
                # UNCHOOSE
                board[r][c] = '.'
                rows[r].remove(d)
                cols[c].remove(d)
                boxes[box_idx].remove(d)
        
        return False  # No valid digit
    
    backtrack(0, 0)
    return board
```

## 7. Word Search

### Definitions

**Core Definition**
Word Search asks whether a given word can be formed by a path of adjacent cells (horizontal or vertical) in a grid, without reusing any cell .

**Technical Definition**
Given an M×N grid of characters and a target word, find a sequence of adjacent cells whose characters spell the word. Each cell can be used at most once per path .

**Beginner-Friendly Explanation**
You have a grid of letters and need to find a word by moving up, down, left, or right. You can't visit the same cell twice in one path.

### Purposes (All begin with "To")

- **To** demonstrate grid DFS with backtracking 
- **To** teach visited marking and state restoration
- **To** provide foundation for path-matching problems
- **To** illustrate search from multiple starting points 

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def exist(board, word):
    rows, cols = len(board), len(board[0])
    path = set()
    
    def backtrack(r, c, i):
        if i == len(word):
            return True
        if not (0 <= r < rows and 0 <= c < cols) or board[r][c] != word[i] or (r,c) in path:
            return False
        
        path.add((r, c))
        for dr, dc in [(0,1), (0,-1), (1,0), (-1,0)]:
            if backtrack(r+dr, c+dc, i+1):
                return True
        path.remove((r, c))
        return False
    
    for r in range(rows):
        for c in range(cols):
            if backtrack(r, c, 0):
                return True
    return False
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `i` | Current index in word |
| `path` | Set of visited cells in current path |
| Start points | Every cell matching `word[0]`  |

```python
    """Check if word exists in board."""

        # Base case: whole word matched
        if i == len(word):

        if (not (0 <= r < rows and 0 <= c < cols) or
            board[r][c] != word[i] or

            if backtrack(r + dr, c + dc, i + 1):
                return True

        path.remove((r, c))
        return False
    
    # Try every cell as starting point
    for r in range(rows):
        for c in range(cols):
            if backtrack(r, c, 0):
                return True
    return False
```

## 8. Graph Coloring

### Definitions

**Core Definition**
Graph coloring assigns colors to vertices such that no two adjacent vertices share the same color .

**Technical Definition**
Given a graph G = (V, E) and k colors, find an assignment of colors to vertices such that for every edge (u, v), color(u) ≠ color(v). The chromatic number is the minimum k for which a valid coloring exists .

**Beginner-Friendly Explanation**
Imagine coloring a map so that no two neighboring countries have the same color. The challenge is to use as few colors as possible.

### Purposes (All begin with "To")

- **To** demonstrate constraint satisfaction with adjacency constraints
- **To** teach backtracking with k-way branching
- **To** provide foundation for scheduling and register allocation 
- **To** illustrate minimum-color search

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def graph_coloring(graph, k):
    n = len(graph)
    colors = [-1] * n
    
    def backtrack(vertex):
        if vertex == n:
            return True
        for c in range(k):
            if is_safe(vertex, c):
                colors[vertex] = c
                if backtrack(vertex + 1):
                    return True
                colors[vertex] = -1
        return False
    
    def is_safe(vertex, c):
        for neighbor in graph[vertex]:
            if colors[neighbor] == c:
                return False
        return True
    
    return colors if backtrack(0) else None
```

```python
def graph_coloring(graph, k):
    """Color graph with at most k colors. Returns colors or None."""
    n = len(graph)
    colors = [-1] * n  # -1 = uncolored
    
    def is_safe(vertex, c):
        """Check if color c is safe for vertex."""
        for neighbor in graph[vertex]:
            if colors[neighbor] == c:
                return False
        return True
    
    def backtrack(vertex):
        # Base case: all vertices colored
        if vertex == n:
            return True
        
        # Try each color
        for c in range(k):
            if is_safe(vertex, c):  # PRUNE
                colors[vertex] = c   # CHOOSE
                if backtrack(vertex + 1):  # EXPLORE
                    return True
                colors[vertex] = -1  # UNCHOOSE
        
        return False  # No color works
    
    if backtrack(0):
        return colors
    return None
```

## 9. Knapsack Problem (0/1 Branch and Bound)

### Definitions

**Core Definition**
The 0/1 knapsack problem asks for the maximum value subset of items that fits within a weight capacity, where each item can be taken (1) or not taken (0) .

**Technical Definition**
Given items with weights w_i and values v_i, and capacity W, maximize sum of selected values subject to sum of selected weights ≤ W. Branch-and-bound uses fractional knapsack (LP relaxation) as an upper bound for pruning .

**Beginner-Friendly Explanation**
You're a thief with a limited backpack. Each item has a weight and value. You must decide which items to take to maximize value without exceeding capacity.

### Purposes (All begin with "To")

- **To** demonstrate branch-and-bound optimization
- **To** teach bounding functions for pruning 
- **To** provide foundation for combinatorial optimization
- **To** illustrate sorting by value/weight ratio 

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def knapsack(items, capacity):
    # Sort by value/weight ratio descending
    items.sort(key=lambda x: x[1]/x[0], reverse=True)
    best = 0
    
    def bound(i, weight, value):
        """Upper bound via fractional knapsack."""
        total = value
        remaining = capacity - weight
        for w, v in items[i:]:
            if w <= remaining:
                total += v
                remaining -= w
            else:
                total += v * (remaining / w)
                break
        return total
    
    def backtrack(i, weight, value):
        nonlocal best
        if value > best:
            best = value
        if i == len(items):
            return
        if bound(i, weight, value) <= best:  # PRUNE
            return
        # Include
        if weight + items[i][0] <= capacity:
            backtrack(i+1, weight + items[i][0], value + items[i][1])
        # Exclude
        backtrack(i+1, weight, value)
    
    backtrack(0, 0, 0)
    return best
```

**Component Breakdown**

| Component | Description |
|-----------|-------------|
| `bound` | Fractional knapsack upper bound  |
| `best` | Best solution found so far |
| Prune | Skip if bound ≤ best |

### Annotated Code Examples

**Example 1: Knapsack with LP Relaxation Bound (Python)**

```python
def knapsack_branch_bound(weights, values, capacity):
    """Solve 0/1 knapsack with branch-and-bound."""
    n = len(weights)
    # Sort by value/weight ratio descending
    items = sorted(zip(weights, values), 
                   key=lambda x: x[1]/x[0], reverse=True)
    weights = [w for w, v in items]
    values = [v for w, v in items]
    
    best_value = 0
    
    def bound(index, current_weight, current_value):
        """Upper bound: fractional knapsack relaxation."""
        total = current_value
        remaining = capacity - current_weight
        for i in range(index, n):
            if weights[i] <= remaining:
                total += values[i]
                remaining -= weights[i]
            else:
                total += values[i] * (remaining / weights[i])
                break
        return total
    
    def backtrack(index, current_weight, current_value):
        nonlocal best_value
        
        # Update best
        if current_value > best_value:
            best_value = current_value
        
        if index >= n:
            return
        
        # PRUNE: bound can't beat best
        if bound(index, current_weight, current_value) <= best_value:
            return
        
        # Include item
        if current_weight + weights[index] <= capacity:
            backtrack(index + 1,
                     current_weight + weights[index],
                     current_value + values[index])
        
        # Exclude item
        backtrack(index + 1, current_weight, current_value)
    
    backtrack(0, 0, 0)
    return best_value


# Demonstration

values = [60, 100, 120]
capacity = 50

print(f"Capacity: {capacity}")
print(f"Maximum value: {max_val}")
```

**Expected Output:**
```

Maximum value: 220
```

**Why This Output Occurs**: Items sorted by ratio: item 2 (30/120=4), item 1 (20/100=5), item 0 (10/60=6). Actually item 0 has highest ratio (6), then item 1 (5), then item 2 (4). Optimal is items 1 and 2 (20+30=50 weight, 100+120=220 value). The bound function prunes branches that can't beat this .

## 10. Hamiltonian Paths / Traveling Salesperson Problem (TSP)

### Definitions

**Core Definition**
A Hamiltonian path visits every vertex in a graph exactly once. The Traveling Salesperson Problem (TSP) finds the shortest Hamiltonian cycle (tour) that visits all vertices and returns to the start .

**Technical Definition**
Given a graph G = (V, E) with edge weights, find a permutation of vertices (v_1, v_2, ..., v_n) minimizing sum of edge weights between consecutive vertices (and v_n to v_1 for TSP). Backtracking explores all (n-1)! permutations, with pruning for optimality .

**Beginner-Friendly Explanation**
A salesperson must visit all cities exactly once and return home, minimizing total travel distance. Backtracking tries all possible orders, abandoning routes that are already longer than the best found.

### Purposes (All begin with "To")

- **To** demonstrate NP-complete problem solving with backtracking
- **To** teach permutation search with optimality pruning 
- **To** provide foundation for vehicle routing and logistics
- **To** illustrate the factorial search space

### Syntax Rules and Structure

**General Syntax (Python)**

```python
def tsp(graph):
    n = len(graph)
    best_cost = float('inf')
    best_path = None
    visited = [False] * n
    
    def backtrack(path, cost):
        nonlocal best_cost, best_path
        
        # Base case: all vertices visited
        if len(path) == n:
            total = cost + graph[path[-1]][path[0]]
            if total < best_cost:
                best_cost = total
                best_path = path[:] + [path[0]]
            return
        
        # PRUNE: current cost exceeds best
        if cost >= best_cost:
            return
        
        last = path[-1]
        for v in range(n):
            if not visited[v] and graph[last][v] > 0:
                visited[v] = True
                path.append(v)
                backtrack(path, cost + graph[last][v])
                path.pop()
                visited[v] = False
    
    visited[0] = True
    backtrack([0], 0)
    return best_path, best_cost
```
